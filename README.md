# Projetos
Sistema de Pedidos em Python

Sistema simples de gerenciamento de pedidos desenvolvido em Python, com integração ao banco de dados MySQL.

O projeto foi desenvolvido como prática de programação e integração entre uma aplicação Python e um banco de dados relacional, utilizando o MySQL através do XAMPP.

Funcionalidades
Adicionar novos pedidos
Armazenar informações do cliente e valor do pedido
Listar pedidos cadastrados
Interação através de menu no terminal
Persistência dos dados em banco de dados MySQL
Tecnologias utilizadas
Python 3
MySQL
XAMPP
mysql-connector-python
Estrutura do banco

O sistema utiliza um banco de dados chamado sistema_pedidos e uma tabela pedidos, responsável pelo armazenamento das informações dos pedidos.

Como executar
Instale o Python.
Instale e execute o XAMPP.
Inicie o serviço MySQL pelo painel do XAMPP.
Crie o banco de dados sistema_pedidos.
Instale a dependência do projeto:
pip install mysql-connector-python
Configure as informações de conexão com o banco de dados no arquivo Python.
Execute:
python pedidos.py
Objetivo

Este projeto faz parte do meu processo de aprendizado em Python, bancos de dados e desenvolvimento de sistemas, servindo como base para projetos futuros com funcionalidades mais avançadas, como CRUD completo, interface gráfica e integração com aplicações web.
